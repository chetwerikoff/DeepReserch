# Seed Candidates for ComposioHQ Agent Orchestrator Analog Research

These are starting points only.

Do not assume that every item is relevant.

Every project must be verified from primary sources before being included in the final ranking.

## Rules for using this seed list

For every seed candidate:

1. Fetch or search primary sources.
2. Verify what the project actually does.
3. Classify it using `research/competitor_filter_criteria.md`.
4. Score it against the target capability baseline from `research/target_project.md`.
5. Remove or downrank it if it is generic, inactive, unrelated, too thin, or lacks real coding-agent orchestration.
6. Prefer official GitHub repositories, official docs, release notes, and maintainer posts.
7. Do not rely on memory.
8. Every important claim must include a source URL.

Also search beyond this seed list for missing analogs.

The final report must not be limited to this seed list.
